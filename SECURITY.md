# Политика безопасности

## Поддерживаемые версии

Поддерживается только последний релиз. Это самый новый тег вида `v.*`. Автообновление ставит его само при запуске Figma.

## Как сообщить об уязвимости

Не открывайте публичный issue. Используйте приватную форму GitHub. Откройте вкладку Security этого репозитория и нажмите Report a vulnerability.

Опишите, что именно можно сделать и как это повторить. Я отвечаю в течение 7 дней и закрываю подтвержденные проблемы новым релизом.

## Что считается уязвимостью

- Запуск постороннего кода через лаунчер, автообновление или `install.ps1`.
- Утечка данных пользователя за пределы figma.com и GitHub.
- Обход проверки подписи при автообновлении.

Уязвимости самой Figma и GitHub сюда не относятся, о них сообщайте им.

## Как проверить релиз

Каждый релиз это подписанный тег. Подпись делается SSH-ключом, его публичная часть лежит в `desktop/allowed_signers`. Автообновление принимает только тег, подпись которого совпадает с этим файлом из уже установленной копии. Тег без подписи или с чужой подписью отклоняется, обновления не будет.

Отпечаток ключа подписи.

```
SHA256:D0RyMd0uWI0MvOkv7ZVj3yTiLBpIhqovVgY4sGlgqLs
```

Проверить тег вручную можно так.

```
git -c gpg.ssh.allowedSignersFile=desktop/allowed_signers verify-tag v.1.40
```
